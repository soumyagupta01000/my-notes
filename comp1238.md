
## Week 1 - History
- One writing system can be used by many languages.
- Cuneiform is an ancient writing system.

## Week 2 - Bits and Bytes
- A bit is a binary digit.
- Eight bits make one byte.

## Week 3 - Text Structure
- Markdown and HTML are used to structure and display text.
- JSON and XML are text-based formats used to store organized data that computers can process.

## Week 4 - Working With Text
- Typing without looking at the keyboard and using all fingers helps improve typing skills.
- RegEx these are used to search for specific characters or patterns in text.

## Week 5 - Command Line Interfaces (CLI)
- Allows users to interact with a computer by typing commands instead of using a graphical interface.
- SSH (Secure Shell) provides an encrypted connection to a remote computer and allows users to run commands on it.
